# Дарвиновский музей: дело о спирали

Интерактивная страница-приключение для ребёнка 6–8 лет, который идёт в Государственный Дарвиновский музей (Москва, ул. Вавилова, 57).

Внутри: 8 проверенных фактов с фото-каруселями, две мини-игры, план маршрута по залам, разбор пяти экспонатов, детективная история, происходящая в самом музее, лента истории места, квест «найди на месте», афиша и раздел для родителя.

Один самодостаточный HTML-файл: вся механика (карусели, игры, бейджи, озвучка, прогресс в localStorage) работает без библиотек. Фотографии подгружаются из Wikimedia Commons.
